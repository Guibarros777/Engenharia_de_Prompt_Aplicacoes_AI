# Engenharia_de_Prompt_Aplicacoes_AI
Repositório Da Faculdade
Prompt Engineering Playground
Um repositório dedicado à experimentação, documentação e compartilhamento de técnicas de engenharia de prompt para modelos de linguagem. Aqui você encontra exemplos práticos, templates, dicas e estudos de caso para criar prompts eficazes, melhorar a qualidade das respostas de IA e explorar diferentes estratégias de interação com LLMs (Large Language Models).
